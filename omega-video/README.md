# O-mega Animation Video

An animated promotional video for [o-mega.ai](https://o-mega.ai) - The Virtual Workforce platform.

## Overview

This 15-second animation showcases o-mega's AI-powered workforce solution with modern, tech-forward visuals matching their brand identity.

### Scenes

1. **Opening Scene (0-3s)**: Company logo reveal with brand colors
2. **Tagline Scene (3-6s)**: "The Virtual Workforce" with typewriter effect
3. **Features Scene (6-12s)**: Key features showcase (AI Workers, Scalability, Automation)
4. **CTA Scene (12-15s)**: Call-to-action with "Try AI Workers" button

### Brand Colors

- Primary Blue: `#0047FF`
- Accent Cyan: `#00F0FF`
- Accent Yellow: `#FAFF00`
- Dark Background: `#0a0e27`

## Usage

### Install dependencies

```bash
npm install
```

### Start development studio

```bash
npm start
```

### Render video

```bash
npm run build
```

The rendered video will be output to `out/video.mp4`.

## Tech Stack

- [Remotion](https://www.remotion.dev/) - Video creation in React
- React 18
- TypeScript
- CSS-in-JS animations

## Video Specifications

- Duration: 15 seconds (450 frames)
- FPS: 30
- Resolution: 1920x1080 (Full HD)
- Format: MP4
